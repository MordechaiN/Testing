# השוואת קרוז – Royal Caribbean, ברצלונה, ספטמבר 2027

כלי **אישי להשוואה** (לא מערכת הזמנות). מזינים הצעות, טיסות, מלון ותוספות – ורואים מיד מה משתלם.

## הפעלה

1. פותחים את הקובץ **`cruise-compare.html`** בדפדפן (לחיצה כפולה). אין התקנה ואין שרת.
2. הנתונים נשמרים אוטומטית **בדפדפן הזה**. לגיבוי או למעבר מחשב: מסך "פרטים ותנאים" ← "ייצוא גיבוי".

המחירים של 12 החדרים שקיבלתם מהסוכנת כבר מוזנים. טיסות, מלון, טיפים ועמלה ריקים.

## שלושה מסכים

| מסך | בשביל מה |
|---|---|
| **סיכום והשוואה** | מה הזול ביותר, טבלה לכל קבוצה בנפרד, פערים בין תאריכים, והצעד הבא |
| **הזנת נתונים** | טופס לכל תאריך וקבוצה, אפשרויות טיסה, אפשרויות מלון, מחירי הסוכנת |
| **פרטים ותנאים** | תנאי הסוכנת, מקדמה (דורש בירור), נוסעים, גיבוי |

## איך משתמשים

**לראות את המחיר הסופי של קבוצה A בלבד**
בראש כל מסך לחצו "רק קבוצה A". קבוצה B נעלמת מכל המסכים ולא משפיעה על שום סכום. הנתונים שלה נשמרים, ואפשר להחזיר אותה בכל רגע.

**לבחור חדר**
במסך הסיכום, בשורה "החדר שבחרתי" בוחרים חדר לכל קבוצה ולכל תאריך (אפשר גם במסך הזנת נתונים). המערכת לא בוחרת חדר לבד ולא מסיקה מסקנות משם החדר. בשורה "החדר הזול ביותר בתאריך" יש כפתור "בחר".

**להוסיף הצעת קרוז**
הזנת נתונים ← "+ הצעת קרוז חדשה" ← מזינים תאריכים. שמות החדרים מועתקים מההצעה הקודמת בלי מחירים. ממלאים מחירים תחת "מחירי הסוכנת – חדרים". חדר בלי מחיר אף פעם לא ייחשב "הזול ביותר".

**להוסיף טיסה**
הזנת נתונים ← בטופס של הקבוצה, ליד "טיסת הלוך" או "טיסת חזור" ← "+ טיסה חדשה". ממלאים פרטים (חברה, שעות, עצירות, זמן כולל, כבודה) ומחירים. אפשר להוסיף כמה אפשרויות לאותו תאריך ולבחור ביניהן. טיסה משותפת לשתי הקבוצות: כל קבוצה בוחרת מהרשימה, והמחיר מחושב לפי מספר הנוסעים שלה.

**להוסיף מושבים ומזוודות**
בכרטיס הטיסה, בטבלת "מחירים לנוסע": שורות "מושב" ו"מזוודה", בעמודות מבוגר ותינוק. הסכום מוצג בנפרד מהטיסה. תינוק לא משלם אלא אם הזנתם לו מחיר (המערכת מזהירה כשמחיר תינוק חסר).

**להוסיף מלון**
הזנת נתונים ← "+ מלון חדש". מזינים תאריכי כניסה ויציאה (הלילות מחושבים לבד), מחיר ללילה, מסים, מס עירייה, ארוחת בוקר ועלויות נוספות. המלון שייך לקבוצה A, לקבוצה B, או לשתיהן. אם המחיר שונה בין הקבוצות, מוסיפים שני מלונות. אם הקבוצה לא נוסעת מוקדם, משאירים "בלי מלון".

**להשוות תאריכים**
במסך הסיכום יש לכל קבוצה טבלה עם עמודה לכל תאריך. מוצגים: קרוז בלבד, כל סעיף בנפרד, סה״כ כל הטיול, מה לא כלול, והפער בין התאריכים. כל קבוצה ותאריך מחושבים לחוד, כך שאפשר לבחור חדר שונה לכל אחד.

**תרחישים**
1. רק A: לחצו "רק קבוצה A".
2. A + B: לחצו "A + קבוצה B". מתחת לטבלאות מופיעה שורת "לידיעה בלבד" עם סכום שתי הקבוצות. זה אף פעם לא המחיר המרכזי.
3. חדרים שונים לכל תאריך וקבוצה: בוחרים חדר בכל עמודה.

## כללי חישוב

```
סה״כ קבוצה = קרוז (החדר שנבחר) + טיסות + מושבים + מזוודות + תוספות טיסה
           + מלון + טיפים + עמלה + שתייה + אינטרנט + תחבורה + אחר
```

- כל קבוצה מחושבת **רק** מהנתונים שלה: חדר, טיסות שבחרה, מלון שבחרה, מספר הנוסעים שלה (ברירת מחדל: A = 2 מבוגרים + תינוק, B = 2 מבוגרים. ניתן לשנות ב"פרטים ותנאים").
- **שדה ריק = 0.** שום שדה לא חובה.
- מחיר טיסה, מושב ומזוודה מוזנים **לנוסע** (מבוגר / תינוק) ומוכפלים במספר הנוסעים.
- "הזול ביותר" נקבע לפי קרוז + מה שהוזן. אם חסרות טיסות באחד התאריכים, מופיע תג צהוב "חלקי". אל תסיקו מסקנה לפני שהוזנו טיסות לכל התאריכים.
- כל הסכומים **בדולרים**. מחיר ביורו צריך להמיר לפני ההזנה.

## מה דורש בירור (לא נוחש במערכת)

- **מקדמה:** נאמר 170$ לאדם / 200$ לחדר / 540$ לזוג. 170$ × 2 = 340$, לא 540$. המערכת לא בוחרת מספר ומאפשרת להזין מקדמה בפועל לכל קבוצה.
- **ביטול:** "אפשר לבטל עד 90 יום לפני המועד ואז הלכה המקדמה". הניסוח לא חד-משמעי, ונדרש אישור בכתב. במסך "פרטים ותנאים" מופיע חישוב של 90 יום אחורה מכל תאריך הפלגה.
- **עמלת סוכנת:** לא ידועה. **טיפים, שתייה, אינטרנט:** לא כלולים במחיר. מיסים: כלולים לפי הסוכנת.

## פיתוח

דרוש Node.js 20 ומעלה.

```bash
npm install
npm run dev        # שרת פיתוח
npm run check      # typecheck + lint + tests
npm run build      # בונה ומעדכן את cruise-compare.html
```

מבנה:

```
src/domain/   חישובים, מצב, שמירה (ללא תלות ב-UI)
src/ui/       שלושת המסכים
tests/        בדיקות חישוב, מצב, שמירה וממשק
cruise-compare.html   הקובץ המוכן לשימוש (נבנה מ-npm run build)
```

אחרי כל שינוי בקוד יש להריץ `npm run build` ולעשות commit גם ל-`cruise-compare.html`.
